# REST API: Workspace, Filesystem, Init, Graph & Export

These 18 routes (20 HTTP operations) power cockpit HTML serving, workspace discovery, multi-stack scaffolding, project analysis, graph retrieval, real-time SSE/version polling, and offline HTML export. All endpoints are protected globally by [`LocalGuard`](./rest-api-overview.md#localguard-transport--anti-csrf-middleware).

{% hint style="info" %}
Unlike project-jailed IDE routes, workspace navigation endpoints (`/api/workspace`, `/api/fs/list`, `/api/analyze`, `/api/init_project`, `/api/export`) accept host filesystem directories by design so you can browse and switch projects from the Cockpit.
{% endhint %}

## GET /api/fs/list

Server-side directory browser used by the Project Hub modal to list system drives and non-hidden subdirectories with stack detection hints.

### 🎮 Endpoint

```text
GET http://127.0.0.1:3030/api/fs/list?path=<dir>
```

### 📝 Parameters

| Name | In | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `path` | Query | `string` | Optional | Directory to list (`\\?\` and quotes stripped; resolves to parent if pointing to a file). Defaults to `project_root.parent()` if it is a directory, otherwise `project_root`. |

### 💎 Response

| Status | Field | Type | Description |
| :--- | :--- | :--- | :--- |
| `200 OK` | `status` | `"ok" \| "error"` | `"error"` if the target path does not exist (`message` contains `"Dossier introuvable : ..."`). |
| `200 OK` | `current_path` | `string` | Canonicalized directory currently listed. |
| `200 OK` | `parent_path` | `string \| null` | Parent directory, or `null` at filesystem root. |
| `200 OK` | `drives` | `string[]` | Available drives (`["C:\\", ...]` on Windows, `["/"]` on Unix). |
| `200 OK` | `entries` | `FsDirEntry[]` | Array of `{ name, path, is_project, stack_hint, is_obsidian }` sorted by `is_project` descending then `name` ascending. Skips dot-folders, `node_modules`, `target`, `dist`, `build`, `__pycache__`, `.venv`, `venv`, `vendor`, `$recycle.bin`, and `system volume information`. `stack_hint` detects `Rust`, `Node / TS`, `Python`, `PHP`, `Go`, `Obsidian Vault`, and `Git`. |
| `200 OK` | `message` | `string` *(optional)* | Present only on error. |
| `403 Forbidden` | *(text)* | `string` | Rejected by `LocalGuard`. |

### 💡 Example

## POST /api/dialog/pick_project

Opens a native OS folder picker dialog to choose a project folder and immediately executes the full `execute_project_pipeline` analysis on it.

### 🎮 Endpoint

```text
POST http://127.0.0.1:3030/api/dialog/pick_project
```

### 📝 Parameters

| Name | In | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| *(none)* | — | — | No | No request body required. |

### 💎 Response

| Status | Field | Type | Description |
| :--- | :--- | :--- | :--- |
| `200 OK` | `status` | `"ok" \| "cancelled"` | `"cancelled"` if the dialog was dismissed. |
| `200 OK` | `project_path` | `string \| null` | Chosen project directory, or `null` when cancelled. |
| `200 OK` | `graph` | `UiGraphPayload \| null` | Analyzed graph serialized via `ui_payload::ser_graph_opt` (compacted if `> 3,000` nodes or `> 20,000` edges), or `null` when cancelled. |
| `403 Forbidden` | *(text)* | `string` | Rejected by `LocalGuard`. |

**Side effects (when `status == "ok"`)**: Updates `project_root`, `project_type`, `detection_report`, `active_view_mode`, `code_graph`, `vault_graph`, and `graph`; reloads `.aether/ai_telemetry_cache.json` on root change; increments `graph_version`; writes `.aether/AETHER_AI_RULES.md` and `.aether/LIVE_AUDIT.md`; updates telemetry and chat messages.

### 💡 Example

```typescript
import { api } from '$lib/api';

const res = await api.pickProject();
if (res.status === 'ok' && res.graph) {
  console.log(`Loaded ${res.graph.nodes.length} nodes from ${res.project_path}`);
}
```

## POST /api/init_project

Scaffolds a contract-driven multi-layer directory tree with YAML-frontmatter `README.md` contracts, a BLAKE3-signed `aether.lock.toml`, `AETHER_AI_RULES.md`, and stack-specific starter files.

### 🎮 Endpoint

```text
POST http://127.0.0.1:3030/api/init_project
```

### 📝 Parameters

| Name | In | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `path` | JSON Body | `string` | **Yes** | Target directory path (created if missing). |
| `stack` | JSON Body | `string` | **Yes** | Stack selector: `"rust"` (`PureRust`), `"python"` (`PurePythonUv`), `"ts"` / `"node"` (`PureNodePnpm`), `"roblox"` / `"roblox-server"` / `"luau"` (`RobloxLuau`), `"minecraft"` / `"mc"` (`MinecraftServer`), `"mvc"` / `"classic-mvc"` / `"clean-mvc"` (`ClassicMvc`), or `"hybrid"` / any other string (`HybridMmoWeb3`). |
| `topology` | JSON Body | `string` | Optional | `"dissociated"` / `"distributed"` (`TopologyMode::Dissociated`) or `"local"` (default, `TopologyMode::MonorepoLocal`). |

### 💎 Response

| Status | Field | Type | Description |
| :--- | :--- | :--- | :--- |
| `200 OK` | `status` | `string` | `"ok"`. |
| `200 OK` | `message` | `string` | Confirmation summary (`"Projet initialisé avec 11 dossiers et contrats README.md signés BLAKE3"`). |
| `200 OK` | `created_dirs` | `string[]` | List of 11 scaffolded subdirectories (`contracts`, `client`, `client/ui`, `client/state`, `server`, `server/domain`, `server/application`, `server/api`, `data-nodes`, `data-nodes/db-primary`, `data-nodes/cache-worker`). |
| `400` / `422` | *(text)* | `string` | Axum JSON extraction error if body is malformed or `path`/`stack` is missing. |
| `403 Forbidden` | *(text)* | `string` | Rejected by `LocalGuard`. |

{% hint style="info" %}
`POST /api/init_project` writes files to disk without running `execute_project_pipeline`. Call `POST /api/analyze` afterward to load the newly scaffolded project into `AppState`.
{% endhint %}

### 💡 Example

```bash

  -H "Content-Type: application/json" \
  -d '{"path":"./my-new-service","stack":"rust","topology":"local"}'
```
{% endtab %}

{% tab title="AetherApiClient" %}

## GET /api/graph

Returns the active `AetherGraph`, either as the cached UI-optimized `UiGraphPayload` (default) or as the uncompacted full graph (`?full=1`).

### 🎮 Endpoint

```text
GET http://127.0.0.1:3030/api/graph
GET http://127.0.0.1:3030/api/graph?full=1
```

### 📝 Parameters

| Name | In | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `full` | Query | `string` | Optional | Pass `"1"` or `"true"` (case-insensitive) to return the full uncompacted `AetherGraph` (including full `edges`, `system_prompt`, and `dataflow_graph`). When omitted or any other value, returns the cached `UiGraphPayload` (with `edges_compact` if `nodes > 3,000 || edges > 20,000`). |

### 💎 Response

| Status | Field | Type | Description |
| :--- | :--- | :--- | :--- |
| `200 OK` | `project_name`, `project_path`, `generated_at` | `string` | Project metadata and timestamp. |
| `200 OK` | `nodes` | `SymbolBubble[]` | Graph bubbles (`raw_content` stripped in UI payload). |
| `200 OK` | `edges` | `AffiliationEdge[]` | Full edge objects (`[]` when compacted). |
| `200 OK` | `edges_compact` | `CompactEdges` *(optional)* | Present only when compacted (`> 3,000` nodes or `> 20,000` edges and `full` is not set). |
| `200 OK` | `stats` | `GraphStats` | Aggregate node/edge/violation metrics. |
| `200 OK` | `system_prompt`, `dataflow_graph` | `string \| null`, `DataflowGraph \| null` | Present only when `?full=1` or `?full=true`. |
| `403 Forbidden` | *(text)* | `string` | Rejected by `LocalGuard`. |

### 💡 Example

{% tabs %}

## GET /api/graph/events

Server-Sent Events (SSE) stream providing sub-150 ms live push notifications from `FileWatcherBridge` for graph rescans, IDE file refreshes, and visual plugin reloads.

### 🎮 Endpoint

```text
GET http://127.0.0.1:3030/api/graph/events
```

### 📝 Parameters

| Name | In | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| *(none)* | — | — | No | Standard SSE subscription (`Accept: text/event-stream`). |

### 💎 Response

| Status | Field (`GraphWatchEvent` JSON in `data:`) | Type | Description |
| :--- | :--- | :--- | :--- |
| `200 OK` (`text/event-stream`) | `version` | `number` (`u64`) | Current `graph_version`. |
| `200 OK` | `visual_version` | `number` (`u64`) | Current `visual_plugins_version`. |
| `200 OK` | `fs_version` | `number` (`u64`) | Current `fs_version`. |
| `200 OK` | `changed_files` | `string[]` | Relative paths modified in the batch (`[]` on initial `"sync"`). |
| `200 OK` | `kind` | `"sync" \| "watcher" \| "visual" \| "lag_resync"` | Event source (`"sync"` on connect, `"visual"` on shader/visual-only edits, `"watcher"` on code/vault edits, `"lag_resync"` if the `128`-slot broadcast buffer lagged). | `403 Forbidden` | *(text)* | `string` | Rejected by `LocalGuard`. |

## POST /api/export

Generates and writes a self-contained offline HTML Cockpit bundle (`aetherscope_viewer.html`) to disk.

### 🎮 Endpoint

```text
POST http://127.0.0.1:3030/api/export
```

### 📝 Parameters

| Name | In | Type | Required | Description |
| :--- | :--- | :--- | :--- | :--- |
| `path` | JSON Body | `string \| null` | Optional | Target output directory. Defaults to `state.project_root`. Always send a JSON object (at least `{}`). |

### 💎 Response

| Status | Field | Type | Description |
| :--- | :--- | :--- | :--- |
| `200 OK` | `status` | `string` | `"ok"`. |
| `200 OK` | `viewer_path` | `string` | Output path (`<target_dir>/aetherscope_viewer.html`). |
| `200 OK` | `total_nodes` | `number` | Node count of `state.graph`. |
| `200 OK` | `total_edges` | `number` | Edge count of `state.graph`. |
| `400` / `422` | *(text)* | `string` | Malformed JSON body (missing `{}`). |
| `403 Forbidden` | *(text)* | `string` | Rejected by `LocalGuard`. |

{% hint style="warning" %}
`POST /api/export` currently ignores `fs::write` errors (`let _ = fs::write(...)`) and still returns `200 OK`. Verify that `viewer_path` exists on disk when automating exports to custom directories.
{% endhint %}

### 💡 Example

{% tabs %}
{% tab title="curl" %}
```bash
curl -s -X POST http://127.0.0.1:3030/api/export \
  -H "Content-Type: application/json" \
  -d '{}'
```
{% endtab %}
